## 📌 Overview

This repository contains the premium engineering project showcase website for **VayuSuchak**, an India-focused airfare intelligence platform that automatically collects dynamic fare observations, standardizes them, detects anomalies, and converts them into an explainable airfare price index designed for **CPI augmentation**.

- **Live Application:** [https://air-fare-index-phi.vercel.app/](https://air-fare-index-phi.vercel.app/)
- **Core Engine Repository:** [https://github.com/Arshu168/VayuSuchak](https://github.com/Arshu168/VayuSuchak)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized bundle will be compiled to the `dist/` directory.

---

## 🌐 Deploy to Vercel

```bash
npx vercel
```
Or import `https://github.com/Fazil-io/vayusuchak-team-web.git` directly on [Vercel](https://vercel.com).
